# segterm

> [!NOTE]
> This project is heavily inspired by [flanterm](https://github.com/mintsuki/flanterm)

> [!TIP]
> If you get an error, its most likely because you're using stable rust.
> To fix it, just switch to nightly

> [!IMPORTANT]
> Segterm is still under development!

## Add as a dependency:

```bash
cargo add segterm
```

> or

```toml
# Cargo.toml
segterm = "^0.1.0"
```
